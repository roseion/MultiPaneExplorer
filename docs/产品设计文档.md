# Windows 多栏文件管理器 · 产品设计文档

> 状态：草案 v0.1（2026-09-05）

## 1. 产品概述

一款 Windows 桌面文件管理器，核心特性是**单窗口内 2/3/4 窗格并列浏览**，每个窗格可独立开关文件树侧栏，让"在多个目录之间浏览、对比、搬运文件"成为一等公民体验。

一句话定位：把 Total Commander 式的双栏效率，用现代、简洁的界面带给普通 Windows 用户。

## 2. 背景与问题

Windows 自带资源管理器单窗口单目录，跨目录复制/移动文件需要开多个窗口来回切换或依赖任务栏，效率低、易出错。现有双栏工具（Total Commander、Directory Opus）功能强大但界面陈旧、学习成本高、收费。

## 3. 目标用户与核心场景

- **目标用户**：经常在多个目录间整理、搬运、对比文件的 Windows 用户（开发者、设计师、办公人员）。
- **核心场景**：
  1. 左栏源目录、右栏目标目录，选中即见，Ctrl+C / Ctrl+V 完成搬运；
  2. 三/四栏并列，同时参考多个目录整理文件；
  3. 开关文件树侧栏，在"树形导航"和"列表聚焦"两种浏览方式间按需切换。

## 4. 设计原则

1. **多栏优先**：所有功能设计围绕多窗格并列工作流，而非单窗口 + 标签页。
2. **每窗格独立**：路径、视图、文件树开关互不干扰。
3. **键盘友好**：高频操作有快捷键，焦点切换清晰。
4. **稳定压倒功能**：文件操作不容出错，宁少勿错。

## 5. 功能规划

### 5.1 MVP（第一期）

| 模块 | 功能 |
|------|------|
| 布局 | 2/3/4 窗格一键切换（2 左右、3 三列、4 田字格）；窗格分隔条可拖拽 |
| 布局 | 每窗格独立的文件树侧栏开关 |
| 浏览 | 详细信息列表（名称、大小、类型、修改时间），点列头排序 |
| 浏览 | 可编辑地址栏、后退/前进/向上、"此电脑"盘符列表 |
| 浏览 | 显示隐藏文件；目录变化自动刷新（FileSystemWatcher） |
| 操作 | 复制/剪切/粘贴（跨窗格）、删除到回收站、F2 重命名、新建文件夹 |
| 操作 | 系统默认程序打开文件；简易右键菜单 |
| 操作 | 窗格间 Tab/F6 切换焦点，F5 刷新 |
| 底线 | 文件操作后台线程执行 + 简单进度提示，不卡 UI |

### 5.2 后续版本

- **第二期**：跨窗格/跨进程拖拽（OLE）、完整系统右键菜单（IContextMenu）、每窗格多标签页、简单搜索与过滤。
- **远期**：缩略图/预览窗格、文件夹对比与同步、批量重命名、撤销、网络路径（UNC/局域网）、OneDrive 占位文件支持。

### 5.3 非目标（明确不做）

- MVP 阶段**不接管系统默认资源管理器**（不处理 Win+E、文件夹双击、Shell 替换注册），仅作为独立应用运行；该能力在核心工作流验证后再单独立项。
- 不做云盘管理、压缩包内置浏览、插件系统、主题市场。

## 6. 技术选型（建议）

- **.NET 8 + WPF**：多窗格用 `Grid` + `GridSplitter` 天然支持；回收站 API、长路径、图标提取等 Windows 能力集成成本低。备选 WinUI 3（界面更现代，成熟度稍逊）。
- 复制进度、同名冲突、UAC/长路径为已知高风险点，MVP 需预留专项调试时间。

## 7. 验收基准（MVP）

1. 双栏场景：左栏选中 10 个文件 → Ctrl+C → 右栏 Ctrl+V，全程无卡顿、结果正确；
2. 任一窗格开关文件树，其余窗格不受影响；
3. 2/3/4 布局切换流畅，拖拽分隔条布局实时调整；
4. 删除进入回收站且可还原；
5. 外部修改目录内容后，列表自动刷新。
