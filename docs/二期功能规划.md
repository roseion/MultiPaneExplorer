## 1. 拖拽增强（优先级最高）

- **移动语义**：同盘拖动 = 移动，按住 Ctrl = 复制，按住 Esc 取消；跨盘拖动默认复制（与资源管理器一致）。
- **视觉反馈**：拖动时显示拖拽内容提示，悬停目标窗格高亮边框，明确落点。
- **拖到文件树**：支持把文件拖到左侧树的某个目录节点上完成移动/复制。
- 说明：核心库已支持复制，需补移动（`File.Move` 语义，含跨盘回退为复制+删除源，失败则整体回滚提示）。
- 验收：同盘拖动后源目录不再保留；Ctrl 拖动保留；跨盘拖动大文件无卡顿。

## 2. 与资源管理器互拖

- 从资源管理器/桌面拖文件进窗格：落地即复制（Ctrl=移动），落点跟随鼠标悬停位置。
- 从窗格拖出到桌面/资源管理器：默认移动（同盘），Ctrl=复制。
- 说明：MVP 已用标准 FileDropList，拖入大概率已可用，需系统化实测补齐边界（权限、大文件）。

## 3. 完整系统右键菜单（技术风险最高）

- 集成 Shell 上下文菜单（IContextMenu COM）：显示第三方注册项（压缩、杀毒、编辑器等）、"打开方式"、"发送到"。
- 难点：COM 互操作、STA 线程与菜单消息循环、多选调用、管理员权限项处理。建议独立迭代，先只读展示再逐步启用。

## 4. 每窗格多标签页

- 每个窗格支持多标签：中键新建、Ctrl+W 关闭、拖拽标签换位；标签记忆各自路径。
- 与现有"窗格常驻、状态保留"的架构兼容（标签组挂在窗格内）。

## 5. 搜索与过滤

- **即时过滤**：Ctrl+F 或 `/` 呼出过滤框，输入即筛选当前列表（名称包含，大小写不敏感）。
- **递归搜索**（可选开关）：搜索当前目录及子目录，结果列表显示相对路径；大目录异步执行 + 取消。
- 验收：10 万项目录下过滤不卡顿（虚拟化 + 增量）。

## 6. 顺带打磨（小成本）

- 会话恢复：记住上次关闭时的布局、各窗格路径与文件树开关状态。
- 属性对话框（大小/时间/只读属性）；"打开方式"子菜单（先系统对话框）。
- 书签/收藏目录（侧栏或下拉），快速跳转常用位置。

## 非目标（继续后置）

云盘与 OneDrive 占位文件、压缩包内置浏览、插件系统、主题市场、接管系统默认资源管理器（该能力单独立项，涉及注册表与 Shell 替换，风险独立评估）。
