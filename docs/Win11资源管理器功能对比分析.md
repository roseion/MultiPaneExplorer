# Windows 11 资源管理器功能分析与差距对比

> 基线：Windows 11 25H2（含截至 2026-04 KB5083631 的公开资料）；对比对象：MultiPaneExplorer v1.4.0。
> 日期：2026-09-05。图例：✅ 已实现 · ⚠️ 部分实现/简化实现 · ❌ 未实现（括注候选/非目标）。

## 1. 结论摘要

"浏览 + 搬运"核心闭环已与资源管理器对齐（剪贴板/拖拽互通、回收站删除、自动刷新、图标、补全），
且**多窗格并列、每窗格标签与树开关是超出 Win11 的差异化能力**。差距集中在六个方向：

1. **视图体系**：只有详细信息视图，缺图标/列表/内容视图与缩略图（已在 v1.5.0 候选）。
2. **操作安全网**：无撤销/重做、无永久删除、无删除确认（撤销已入候选）。
3. **导航体系**：地址栏无面包屑、树无"快速访问/此电脑分级/回收站/网络"节点、无最近文件（面包屑已入候选）。
4. **右键菜单**：仅 11 项自绘菜单，缺发送到、压缩/解压、永久删除、完整 Shell 扩展（后者为已知限制）。
5. **属性与元数据**：缺详细信息/预览窗格（预览窗格已入候选）。
6. **搜索**：有本目录过滤与递归搜索，但无搜索框 UI、无内容搜索、无 AQS 过滤器。

其余差距（OneDrive、网络邻居、库、AI 操作、索引搜索等）属于既定非目标或低价值项，建议不跟进。

## 2. Win11 资源管理器功能全景与逐项对比

### A. 窗口模型与标签

| Win11 功能 | 说明 | 我们 |
|---|---|---|
| 多实例窗口 | Ctrl+N 新窗口、任务栏多窗口 | ❌（可低成本低成本补 Ctrl+N） |
| 多标签页 | 单窗口多标签、中键关、拖拽换位、拖出成窗 | ✅ 每窗格多标签（中键新建/Ctrl+W/拖拽换位）；拖出成窗 ❌ |
| 会话恢复 | "登录时还原以前的文件夹窗口"，25H2 起以标签恢复 | ✅ 恢复布局/各窗格路径/树开关（含标签） |
| 并排分栏 | 无原生多栏（仅系统级 Snap） | ✅ **超出**：2/3/4 窗格 + 分隔条拖拽 |

### B. 导航体系

| Win11 功能 | 说明 | 我们 |
|---|---|---|
| 导航窗格 | 快速访问（固定+常用）、OneDrive、此电脑（盘符+用量条）、网络、回收站；可折叠 | ⚠️ 每窗格目录树（盘符+.lnk 解析）+ 顶部★收藏下拉；缺固定/常用自动推荐、回收站/网络节点、盘符用量条 |

### C. 命令栏与右键菜单

## 4. 我们超出 Win11 的能力（差异化，持续强化）

1. **2/3/4 窗格并列浏览**——跨目录对比、搬运无需多窗口切换（产品立足点）。
2. **每窗格独立文件树侧栏**——树导航与列表聚焦可按窗格混搭。
3. **每窗格多标签**——窗格内多目录常驻，状态互不干扰。
4. **跨栏工作流一等公民**——Ctrl+C/V 跨窗格、拖拽到树/到窗格、焦点 F6 快速轮转。
5. **即时过滤**——Ctrl+F 输入即筛，比 Win11 的搜索框更轻量直达。
