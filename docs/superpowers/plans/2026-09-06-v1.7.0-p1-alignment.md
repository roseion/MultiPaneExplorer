# v1.7.0（对比文档 P1 前半 + 二期候选）实施计划

> **For agentic workers:** 按任务逐个实现，每任务独立 commit，checkbox 跟踪进度。

**Goal:** 完成二期候选六项：删除安全网（Shift+Del）、冲突/进度对话框升级、列管理（列宽/可选列）、
预览窗格（图片/文本）、UAC 重试、视频/PDF 缩略图。

**Spec:** `docs/Win11资源管理器功能对比分析.md` §3 P1 #6-9；`docs/二期功能规划.md` v1.7.0 候选行。

**Architecture:** 核心能力（永久删除、提权辅助进程执行器、CopyProgress 项目计数、列布局会话字段）
全部落 FileOps.Core 配 xUnit；App 层只做接入（进度窗、预览栏、列头模板、Shell 缩略图 COM 互操作）。

**Tech Stack:** .NET 8 WPF、CommunityToolkit.Mvvm、xUnit。零新 NuGet 依赖。

## Global Constraints（含未收到回复时按推荐执行的四个默认决策）

- 每任务独立 commit，交付前 `dotnet build` + `dotnet test MultiPaneExplorer.slnx` 全绿
  （dotnet test 不重建 App 工程，必须先显式 build）。
- 核心逻辑进 FileOps.Core 并配单测；UI 手动验收；中文注释与提交信息。
- 决策①范围=全部六项；②预览=全局右侧预览栏（Alt+P+标题栏按钮，跟随激活窗格选中项，随会话记忆）；
  ③UAC=提权辅助进程（runas 启动自身 `--elevated-op <payload>`，结果经 JSON 回传，单次操作提权）；
  ④进度=非模态窗口（进度条+项目计数+当前文件+取消，400ms 防闪烁）。
- 视频缩略图（IShellItemImageFactory）为进程内 Shell 互操作，全部 try/catch 包裹、失败回退系统大图标；
  若实机测试出现不稳定，单独回退该项不阻塞整版。
- 提权重试的传输不进撤销栈（撤销在普通权限下会再次失败），状态栏注明"（管理员）"。
- 回收站视图内 Del 永久删除补确认框（原先无确认）。
