# v1.9.0（体验打磨版）实施计划

> **For agentic workers:** 按任务逐个实现，每任务独立 commit，checkbox 跟踪进度。

**Goal:** 补齐自绘标题栏的原生交互、快捷键缺口、ZIP 解压、标签拖拽重排，并建立发布工程，
让应用可直接分发使用。

**Spec:** 用户确认的 v1.9.0 打磨清单（A 标题栏原生交互 / B 快捷键 / C ZIP 解压 /
D 标签拖拽重排 / E 发布工程）；暗色主题留作 v2.0 主打。

**Architecture:** 解压核心进 ZipHelper 配 xUnit；其余为 App 层交互（系统菜单走
SystemCommands、贴靠弹窗自绘 Popup + Win32 工作区计算、快捷键挂 Pane_PreviewKeyDown、
标签拖拽用 DragDrop 数据对象）。

**Tech Stack:** .NET 8 WPF、CommunityToolkit.Mvvm、xUnit。零新 NuGet 依赖。

## Global Constraints

- 每任务独立 commit，交付前 `dotnet build` + `dotnet test MultiPaneExplorer.slnx` 全绿
  （构建前先 taskkill 运行中的实例，DLL 会被锁）。
- 核心逻辑进 FileOps.Core 并配单测；UI 手动验收；中文注释与提交信息。
- 视觉 token 一律走 W11.*（MASTER.md v3 铁律）。
