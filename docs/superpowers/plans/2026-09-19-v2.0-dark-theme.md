# v2.0（暗色主题 + 个性化）实施计划

> **For agentic workers:** 按任务逐个实现，每任务独立 commit，checkbox 跟踪进度。

**Goal:** 全套暗色主题（Finder 暗色风）、浅/深/跟随系统三态切换、会话记忆，作为 v2.0 交付。

**Spec:** 用户确认的 v2.0 方向（暗色主题跟随系统优先于功能项）；真 Acrylic、红绿灯钮、
复制速度/暂停、冲突比较视图留 v2.1。

**Architecture:** 现有 `Win11Theme.xaml` 中的全部颜色 token 抽到 `Theme.Tokens.Light.xaml` /
`Theme.Tokens.Dark.xaml`（键名完全一致，都沿用 W11.* 前缀避免全库改动）；
`ThemeManager` 运行时替换合并字典；样式/模板留在基础字典引用 token（DynamicResource 不需要——
换字典后 StaticResource 已加载的值会过期，故改用动态重载合并字典 + 让引用 token 的样式也在
token 字典之后合并；实测采用"样式字典引用 token 用 DynamicResource"的最小改造方案）。

**Tech Stack:** .NET 8 WPF、CommunityToolkit.Mvvm。零新依赖。

## Global Constraints

- 每任务独立 commit，交付前构建+115 单测全绿（构建前 taskkill）。
- 组件内禁止裸 hex（含此轮新改的文件）。
- 主题切换不得重启应用、不得丢会话状态。
