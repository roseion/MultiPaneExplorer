# v1.8.0（对比文档 P1 #10-14）实施计划

> **For agentic workers:** 按任务逐个实现，每任务独立 commit，checkbox 跟踪进度。

**Goal:** 完成 P1 后半五项：树/收藏升级、此电脑用量条+known folders、右键菜单扩项、
搜索体验统一（相对路径列）、Ctrl+N 新窗口+键入跳转。

**Spec:** `docs/Win11资源管理器功能对比分析.md` §3 P1 #10-14。

**Architecture:** 核心能力（常用目录计数、ZIP 压缩、快捷方式创建）落 FileOps.Core 配 xUnit；
App 层做树右键菜单、收藏菜单升级、树模板用量条、右键扩项、位置列与键入跳转。

**Tech Stack:** .NET 8 WPF、CommunityToolkit.Mvvm、xUnit、System.IO.Compression（内置）。零新 NuGet 依赖。

## Global Constraints

- 每任务独立 commit，交付前 `dotnet build` + `dotnet test MultiPaneExplorer.slnx` 全绿
  （dotnet test 不重建 App 工程，必须先显式 build）。
- 核心逻辑进 FileOps.Core 并配单测；UI 手动验收；中文注释与提交信息。
- 范围裁剪：拖拽到收藏按钮、"比较"冲突视图、速度/暂停进度、批量重命名维持后置（P2）。
- 展开到当前文件夹 v1.6.0 已实现（RevealInTree），本版不再重复。
